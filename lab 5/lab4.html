Relative Positioning Demonstration

Key Concept: When using position: relative with the top property, the element visually moves but its original space in the document flow is still reserved.

1️⃣ This is the first normal text block (position: static)

2️⃣ This caption uses position: relative with top: -30px — Notice it moves UP but the gap below shows its reserved space!

3️⃣ This third text block stays in its normal position, but there's a gap above it because the red caption's original space is still reserved in the document flow.

Observation: The red caption appears to overlap the first text block, but the space where it would have been (between blocks 1 and 3) remains empty. This is the key difference between position: relative and position: absolute.

About This Project

This webpage demonstrates fundamental CSS positioning concepts without using modern layout techniques like Flexbox or Grid.

The techniques used include:

  • Fixed positioning: Header and back-to-top button
  • Absolute positioning: Image overlays and corner badges
  • Relative positioning: Caption offset demonstration
  • Float layout: Image gallery arrangement
