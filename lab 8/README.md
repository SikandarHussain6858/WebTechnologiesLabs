# Lab 08: Media Queries and Responsive Web Design

## Description

This lab implements a responsive web page designed to mimic the layout of the BBC News website. The page uses HTML5, CSS3, and media queries to create three distinct layouts for smartphone, tablet, and desktop viewports. The layout includes a top bar with branding and navigation, a welcome section, a lead story grid, and separate news and sports sections.

## Features

- **Responsive Design**: The layout adapts automatically based on screen size using CSS media queries.
- **Desktop Layout (>1024px)**: Top bar with logo and navigation, grid-based content layout with lead story and side stories.
- **Tablet Layout (768px - 1024px)**: Adjusted grid layout with single-column lead stories.
- **Mobile Layout (<768px)**: Stacked vertical layout with centered branding and vertical navigation menu.

## Technologies Used

- HTML5 for structure
- CSS3 for styling and responsiveness
- CSS Grid for layout management
- Media queries for breakpoint handling

## Files

- `index.html`: Main HTML file containing the page structure
- `style.css`: CSS file with styles and media queries
- `README.md`: This description document
